\section{Background}

\subsection{Imputation methods in survey practice}

Survey agencies and microsimulation teams draw on a small set of imputation
families. \emph{Hot-deck and statistical matching} methods donate observed
values from a matched donor record. They preserve marginal distributions by
construction, because every imputed value is a real donor value
\citep{andridge2010review, dorazio2006statistical}, and they remain the
standard data-fusion tool in European microsimulation practice
\citep{sutherland2013euromod}. \emph{Regression-based} methods impute from a
fitted conditional model (ordinary least squares with residual draws
\citep{vonhippel2013should}, linear quantile regression
\citep{koenker1978regression, koenker2005quantile}) and extend to multiple
imputation for uncertainty propagation \citep{rubin1987multiple,
kennickell1998multiple}. \emph{Tree-ensemble} methods, in particular quantile
regression forests \citep{meinshausen2006quantile, breiman2001random},
estimate full conditional distributions nonparametrically. They are the
default in \policyengine{}'s data pipelines \citep{ghenis2018quantile,
woodruff2024enhancing} because they capture nonlinear structure without
per-variable specification. The \microimpute{} package
\citep{policyengine2025microimpute} implements these families under one
interface and selects among them by cross-validation. Its central finding,
that no family dominates across datasets, motivates comparing methods
empirically on each new task.

\subsection{Chained imputation and joint structure}

Imputing several variables one at a time, each conditional only on shared
predictors, drops whatever dependence among the imputed variables the
predictors do not carry. Sequential (chained-equations) imputation
conditions each variable on those already imputed and so retains joint
structure \citep{raghunathan2001multivariate, vanbuuren2011mice}. In data
fusion the same issue appears as the conditional independence assumption of
statistical matching: matched files preserve marginals but attenuate
cross-source correlations \citep{dorazio2006statistical}. Synthetic-data
generation faces the same trade-off at whole-file scale
\citep{rubin1993statistical}.

\subsection{Weights in imputation}
\label{sec:background-weights}

Design weights enter imputation practice unevenly. The model-based literature
often treats weights as a nuisance: if the model is correctly specified and
conditions on the design variables, weighting is unnecessary. The
design-based tradition weights every estimator \citep{little2002statistical}.
A production microdata pipeline can rarely claim a correctly specified model
or the full set of design variables, so the choice can matter. An unweighted
fit targets the sample conditional, and any correlation between weights and
outcomes within predictor cells carries into the imputed population
distribution. \citet{reiter2006importance} show by simulation that
multiple imputation which ignores the design can be severely biased when the
design features are related to the survey variables, and that controlling for
those features in the imputation model reduces the bias.

Where the design cannot be modeled, it can be undone by resampling. Inverse
sampling draws subsamples that have the structure of simple random samples
\citep{hinkins1997inverse}. The weighted finite population Bayesian bootstrap
generates synthetic populations in which the unequal selection probabilities
are inverted \citep{dong2014nonparametric}, so that imputation methods built
for independent, identically distributed data can be applied to them
\citep{zhou2016two}. The weighted bootstrap of Section~3 is a simple relative
of these methods: donor rows are redrawn with probability proportional to
weight before each forest is grown. It is one resample per forest and carries
none of the finite-population machinery those methods use for inference,
because the product here is a drawn file, not a variance estimate. The
closest precedent in software is this paper's own forest baseline:
\microimpute{} resamples its training rows with replacement in proportion to
weight before fitting \citep{policyengine2025microimpute}. It draws one
resample at a fixed seed and shares it across all chained targets, where the
estimator here draws a fresh one for each forest, and it has no gate. The
contrast between the two forests in Section~\ref{sec:results} is therefore
not a weighting contrast.

Tree ensembles add a mechanical reason to resample. A fully grown forest
predicts from the training rows stored in its leaves, and per-record weights
passed to the forest do not reweight those rows, so honoring weights
requires putting them into the training data. Zero-inflated
targets add a second consideration: weighting the zero/nonzero gate by
resampling can delete a rare sign class outright, so the gate must be
weighted directly. Weighting by resampling is not new. We are not aware of
prior survey-imputation work that combines it with sign gating and
chaining in one forest estimator whose interface makes the weighted fit the
default. This paper documents and tests that combination.

\subsection{Evaluating imputed files}

Because an imputation is a draw from an estimated conditional distribution,
pointwise accuracy metrics understate quality; the relevant question is
distributional. We report pinball loss, from the quantile-loss tradition
\citep{koenker2005quantile, meinshausen2006quantile}, and Wasserstein
distance; as computed here both score marginal fit
(Section~\ref{sec:metrics}). For the joint distribution we use the
population-view harness of \citet{ghenis2026popdgp}, which treats surveys as
partial views of one population and scores a candidate file through each
view against a held-out sample of that survey. This paper is its first
application: Section~\ref{sec:harness} summarizes the four metrics it
reports, and the framework's general treatment is in that work. The
reweighting fragility diagnostic of Section~\ref{sec:metrics} is, to our
knowledge, new.
